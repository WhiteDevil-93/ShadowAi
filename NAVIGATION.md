# Repo Navigation Guide

AI agents and contributors should find the essential orientation materials at the repository root.

Key reference files:

- `AGENTS.md` – project-wide guidance, phases, trusted patterns.
- `WORKTREE.md` – minimal list of files required to build/run the app.
- `README.md` (archived at `archive/clutter/README.md`) – high-level architecture summary plus workspace hygiene note.

If you need a deeper dive into any of those topics, open the files above or the archived notes inside `archive/clutter/` from the root workspace.

For everything else, rely on the living source tree (`app/`, `backend/`, `provider-adapters/`, etc.) and the `plans/` documents that now also live in `archive/clutter/` if needed.
