## ADR Format

Each ADR follows this structure:

- **Title**: Descriptive name of the decision
- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: Background and problem statement
- **Decision**: The chosen approach
- **Consequences**: Trade-offs and implications
- **References**: Related documents or code

## Contributing

When proposing new architectural decisions:

1. Create a new ADR using the next available number
2. Use the template from existing ADRs
3. Submit for team review
4. Update this index
